中3 国語文法アプリ ― 社会式トップ・iPad最適化版
================================================

今回の改修
・起動直後は問題を表示せず、社会アプリのような分野選択トップ画面を表示
・7分類カードから選択後に問題画面を開く
・問題画面に「トップ」ボタンを追加
・トップ画面で「未回答だけ／できなかった問題だけ／できただけ」と難易度を選択
・問題画面から分類操作を外し、縦方向を大幅に節約
・iPadで答え＋解説＋自己採点が見えやすいよう全体をさらに圧縮
・答え表示時の自動スクロールを廃止

単語・文節区切り問題
・元の文を手書き欄内にDOMテキストとして常時表示
・その上からApple Pencil等で「／」を書き込める
・「消す」を押しても元の文は消えず、手書きだけ消える

7分類
1. 文・文節・単語
2. 品詞の基本
3. 自立語の品詞
4. 用言・活用
5. 助詞
6. 助動詞・識別
7. 敬語

使い方
ZIPを展開し、index.html をSafari / Chrome / Edge等で開いてください。
オフラインで動作します。
