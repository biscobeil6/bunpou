中3 国語文法アプリ ― 学習記録・7分類対応版
==============================================

収録：
・GQ00001～GQ00747 全747問
・Claudeダブルチェック反映済み問題データ

追加機能：
・答えを見たあと「できた／できなかった」を記録
・「できなかった問題だけ」「未回答だけ」「できただけ」で出題可能
・7分類で出題範囲を選択
・細分類、難易度、京都重要度でも絞り込み可能
・分類別の完了数／できなかった数を表示
・学習記録はブラウザのlocalStorageに保存
・ランダム出題
・大きな手書き欄

7分類：
1. 文・文節・単語
2. 品詞の基本
3. 自立語の品詞
4. 用言・活用
5. 助詞
6. 助動詞・識別
7. 敬語

使い方：
ZIPを展開し、index.html をSafari / Chrome / Edge等で開いてください。
オフラインで動作します。
