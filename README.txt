中3 国語文法アプリ ― iPadレイアウト・トップ操作対応版
=====================================================

今回の改修
・iPadで「答え＋できた／できなかった」まで見えやすいよう、手書き欄と余白を縮小
・単語分け／文節分けなど「／」を書き込む問題では、元の文を手書き欄に印字
  → 印字された文の上からApple Pencil等で「／」を書き込めます
・「消す」を押しても元の文は残り、手書きだけ消した状態に戻ります
・7分類をトップ画面に常設
・「すべて／未回答／できなかった／できた」をトップから切替
・難易度もトップから切替
・歯車は細分類、京都重要度、ランダム、分類別進捗など詳細設定用
・従来の「できた／できなかった」記録と復習機能は継続

7分類
1. 文・文節・単語
2. 品詞の基本
3. 自立語の品詞
4. 用言・活用
5. 助詞
6. 助動詞・識別
7. 敬語

使い方
ZIPを展開し、index.html をSafari / Chrome / Edge等で開いてください。
オフラインで動作します。
