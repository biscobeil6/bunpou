中3国語文法アプリ 単一HTML修正版

この版は index.html 1ファイルだけで動作します。
CSS・全747問・文法資料80項目・JavaScriptをすべて内蔵しています。

確認ポイント
・トップの「文法資料」を押すと資料画面が開く
・敬語の最初の2問は同じ分類問題ではありません
  1問目：尊敬語とは何か → 尊敬語
  2問目：「先生が言う」を尊敬語に → 先生がおっしゃる
・トップに「v5・文法資料内蔵・敬語再設計」と表示されます

使い方
ZIPを展開し、このフォルダの index.html を開いてください。
以前のフォルダではなく、この新しいフォルダの index.html を使用してください。
